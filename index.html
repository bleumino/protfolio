Machine Learning / Python

F1 Finishing Position Prediction

Built and compared five regression models to predict an Formula 1 driver's finishing position using starting grid position and constructor information.

The project used Formula 1 race data from 2018 onward and explored Linear Regression, K-Nearest Neighbours, Decision Tree, Random Forest and a PyTorch neural network.

I also tuned KNN and Decision Tree models using GridSearchCV. Random Forest achieved the best test R² of approximately 0.43 on a random 80/20 split. Interestingly, all five models performed within 0.025 of each other, suggesting that the limited input features restricted the benefits of more complex models.
