Projects

ML Project

F1 Finishing Position Prediction: Built and compared five regression models (linear regression, KNN, decision tree, random forest and a PyTorch neural network) to predict an F1 driver’s finishing position from starting grid and team, using race data from 2018 onward; tuned KNN and the decision tree with GridSearchCV. Best test R² was about 0.43 (random forest) on a random 80/20 split. All five models scored within 0.025 of each other, so with only two input features the more complex models added little over linear regression.
